# Ansible4Networking

A community-driven repository of demos, labs, and playbooks from the [Ansible4Networking](https://www.meetup.com/ansible4networking/) meetup group — focused on **network automation with Ansible**.

## What is Ansible4Networking?

Ansible4Networking is a free, open community dedicated to helping network engineers adopt automation using [Red Hat Ansible Automation Platform](https://www.ansible.com/). Founded and organized by [Tony Dubiel](https://www.linkedin.com/in/dubielcoding/) — Principal Specialist Solution Architect at Red Hat and triple CCIE #10844 — the group brings together network professionals through monthly online meetups, study groups, hands-on labs, and live demos.

Each meetup session features a speaker in the first half and a live demo in the second half, with all recordings available on [YouTube](https://www.youtube.com/@ansible4networking).

## Topics Covered 

- **IOS Upgrades** — automating Cisco IOS upgrades with Ansible
- **ZTNA with Ansible** — automating Zero Trust Network Accesswith Ansible (webinar Sept 9th)
- **Protect the Network with PSIRT API and Ansible** — The PSIRT openVuln API and Ansible Automation
